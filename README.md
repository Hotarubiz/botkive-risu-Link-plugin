# 봇카이브 등록 플러그인

PocketRisu에서 캐릭터를 골라 [봇카이브](https://github.com/Hotarubiz/borkive_fork) 서재에 등록하는 플러그인이에요.

## 설치

1. 봇카이브를 설치하고 PocketRisu 연동을 켜요. 방법은 [봇카이브 README](https://github.com/Hotarubiz/borkive_fork#pocketrisu-연동)에 있어요.
2. 이 저장소의 [`dist/botkive-link.js`](dist/botkive-link.js)를 받아요.
3. PocketRisu 플러그인 설정에서 이 파일을 추가해요. 같은 이름의 이전 판은 새 파일로 바뀌어요.

**봇카이브와 플러그인은 같이 업데이트하세요.**

## 사용법

1. PocketRisu의 **요청 로그 기능은 꺼 두세요.** 플러그인 메뉴에서 **봇카이브 등록**을 열어요.
2. **봇카이브 연결**에 봇카이브 도메인과 페어링 코드를 넣고 **형식 확인** → **연결 확인**을 눌러요. 코드는 봇카이브의 **PocketRisu 연결** 단추에서 만들어요.
3. **캐릭터 목록 조회** → 캐릭터를 골라요. 처음에는 1개만 시험해 보세요.
4. **선택한 캐릭터 등록…** → 확인 화면을 읽고 체크 → **등록 시작**을 눌러요.

보내는 동안 **－(최소화)** 단추로 창만 숨길 수 있어요. 멈추려면 **등록 중단**을 누르세요. PocketRisu를 새로 고치거나 닫으면 전송이 멈춰요.

## 보내는 자료

**보내는 것:** 캐릭터 글(이름·설명·성격·시나리오·첫 메시지·예시 대화·제작자 노트·시스템 프롬프트 등), 대체 인사말·태그, 로어북과 그 설정, 표시용 정규식, 대표 이미지와 카드에 적힌 에셋(표정·추가 에셋), 캐릭터가 속한 폴더.

**보내지 않는 것:** 채팅 기록, 개인 설정·API 키·로그인 정보·쿠키, 다른 캐릭터와 모듈 전체, 카드에 적히지 않은 파일, 트리거 스크립트·음성 설정·배경 HTML.

- PocketRisu 원본은 읽기만 하고 바꾸지 않아요.
- 캐릭터를 고르고 전송을 누르는 건 사용자예요. 사용자 조작 없이는 보내지 않아요.
- 설명이나 로어북 본문에 직접 적은 비밀정보는 가려내지 못해요.
- 페어링 코드는 기본으로 저장하지 않아요. **이 브라우저에 코드 기억하기**를 켜면 그 기기의 브라우저에 저장하는데, 이 저장 공간은 다른 플러그인도 읽을 수 있어요.

전송 한도와 문제 해결은 [봇카이브 README](https://github.com/Hotarubiz/borkive_fork#보낼-수-있는-크기)를 보세요.

## 직접 빌드하기

Node.js만 있으면 돼요. 설치할 패키지는 없어요.

```bash
node build.js
```

`src/`의 파일을 묶어 `dist/botkive-link.js`를 만들어요.
